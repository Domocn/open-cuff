# Open Cuff (Android app)

The Flutter app. See the [main README](../README.md) to install it, and [PRIVACY.md](../PRIVACY.md).

Build: `flutter pub get`, `flutter test`, `flutter build apk --release`. Release builds use the maintainer's key when
`android/key.properties` (or `~/.keys/open-cuff/key.properties`) exists, otherwise Flutter's debug key.
